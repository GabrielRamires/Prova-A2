# Prova-A2 Mapeamento
Prova A2 da Competição Catarinense de Drones

Esse código foi criado para fazer a prova de Mapeamento de forma autonoma.
No Presente momento é  um sistema de visão computacional que detecta e localiza formas geométricas em uma superfície de 80×80 cm, usando um marcador ArUco como referência de origem e orientação.
Funciona **independente da rotação da imagem**.
